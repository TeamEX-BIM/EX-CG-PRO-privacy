EX EXSTREAM PRO — CG MANAGER

Privacy Policy

What Ex CG Manager does with data on your machine, in plain terms — and, mostly, what it doesn't do with it at all.

Effective September 5, 2026 Applies to Exstream Pro – CG Manager, all versions (Revit 2024–2027) Publisher TEAM EX

Ex CG Manager is a Revit add-in that calculates and marks the center of gravity for selected elements. It runs entirely inside your local Revit session. The short version: it doesn't talk to the internet, doesn't collect analytics, and never sees your model data — everything below explains exactly what it does store, and where.

§1

What this add-in does

Ex CG Manager adds one command to the Revit ribbon (Ex CG Pro). When you run it against selected elements, it computes their combined center of gravity, volume, and — where material density data is available — an estimated weight, then either places a marker family at that point, writes the results onto the selected elements' own parameters, or exports a CSV report. All of this computation happens inside the Revit process on your computer, using the Revit API.

§2

Your models and project data

The add-in reads geometry, material, and volume information only from the elements you actively select, and only for as long as it takes to run the calculation you asked for. Results are written back into your own Revit project — as parameter values on your elements, or as a marker family instance — and nowhere else.

We do not upload, transmit, cache, or retain any part of your Revit model, project file, or geometry. There is no server this add-in talks to.
§3

Licensing data, stored locally

Ex CG Manager offers a free 14-day trial and a paid Pro tier. To tell the two apart, it stores a small amount of data — entirely on your own machine, entirely offline:

  • Pro license key — if you activate Pro, the key you enter (which embeds the email address associated with your purchase) is saved to %AppData%\ExstreamPro\CGManager\license.key and verified using public-key cryptography, performed locally. It is never sent anywhere for validation.
  • Trial start date — recorded once, in a small local file and a matching Windows registry value under HKEY_CURRENT_USER\Software\ExstreamPro\CGManager, so the 14-day count is accurate even if one copy is deleted.

Neither of these ever leaves your computer. Uninstalling the add-in and deleting the files above removes them completely.

§4

CSV export

The Export CG Report feature writes a CSV file (Mark, ID, Material, Volume, Weight) to a location you choose yourself, using the standard Windows file save dialog. That file is yours from the moment it's created — we have no access to it and no visibility into where you save it or what you do with it afterward.

§5

Third parties

Ex CG Manager does not integrate any analytics SDK, crash reporter, advertising network, or other third-party service. Because no usage or personal data is collected beyond the license information described in §3, none is shared with or sold to anyone.

§6

Children's privacy

Ex CG Manager is a professional BIM tool distributed through the Autodesk App Store and is not directed at children. We do not knowingly collect information from anyone under the age of 16.

§7

Changes to this policy

If what this add-in stores or how it behaves ever changes, this page will be updated and the effective date above revised accordingly. Since the add-in has no update-check mechanism of its own, we'd recommend checking this page directly if you want the latest version.
